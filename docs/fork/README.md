# Наш форк La Suite Meet

Это сервис видеосвязи для онлайн-сессий психотерапии. Он нужен там, где у клиентов не работают иностранные сервисы, а российские не годятся по качеству. За основу взят [La Suite Meet](https://github.com/suitenumerique/meet) — открытая видеосвязь французского государства на LiveKit (лицензия MIT).

Главное требование — конфиденциальность. Всё, что касается звука, видео, записей и расшифровок, оцениваем прежде всего с этой стороны: где хранятся данные, кто их видит и уходят ли они за пределы нашего сервера.

## Из чего состоит

| Часть | Где лежит | Что делает |
|---|---|---|
| Бэкенд | `src/backend` | Django: комнаты, пользователи, доступы, выдача токенов LiveKit, письма |
| Фронтенд | `src/frontend` | React + Vite + Panda CSS: всё, что видит человек в браузере |
| LiveKit | отдельный сервер | Медиасервер (SFU): принимает и раздаёт звук и видео |
| Агенты и summary | `src/agents`, `src/summary` | Расшифровка и краткий итог встреч через внешние модели; включать только после отдельной оценки приватности |
| Helm, SDK, письма | `src/helm`, `src/sdk`, `src/mail` | Развёртывание в Kubernetes, встраивание, шаблоны писем |

Как развёрнуто у нас — в [deployment.md](deployment.md).

## Чем мы отличаемся от апстрима

Наша база — релиз апстрима `v1.33.0` (30.09.2026). Сверху лежат только наши изменения:

- русский язык интерфейса и писем; он же язык по умолчанию (`src/frontend/src/locales/ru`, `src/backend/locale/ru_RU`);
- мобильная вёрстка диалогов, настроек, окна приглашения и боковой панели;
- сборка образа фронтенда в GHCR (`.github/workflows/build-frontend.yml`) и мелкие исправления CI;
- скрипты обследования сервера `bin/inspect-deployment.sh` и `bin/inspect-meet-config.sh`;
- документация форка (эта папка) и `CLAUDE.md` с правилами для сессий с Claude.

Почему что-то сделано именно так — в [decisions.md](decisions.md). Планы и проекты функций — в отдельных файлах этой папки, например [catch-up-audio.md](catch-up-audio.md).

## Как подтягивать новые версии апстрима

Апстрим выпускает минорные релизы почти каждую неделю. Раньше форк отстал на 33 релиза, и чинить такое приходится пересборкой. Поэтому лучше подтягиваться регулярно, раз в 1–2 месяца.

```bash
git remote add upstream https://github.com/suitenumerique/meet.git   # один раз
git fetch upstream --tags
git checkout -b sync/vX.Y.Z main
git merge vX.Y.Z            # релизный тег, не upstream/main
```

После слияния:

1. Прочитать `UPGRADE.md` и `CHANGELOG.md` апстрима за пропущенные версии. Там бывают обязательные шаги для сервера.
2. Догнать русский перевод. Новые ключи появляются в `src/frontend/src/locales/en/*.json`; их нужно добавить в `ru/`, соблюдая русские множественные формы (`_one`, `_few`, `_many`, `_other`).
3. В `src/frontend` выполнить `npm ci && npm run check && npm run lint && npm run build`.
4. Обновить базовую версию в этом файле.

## Языки

Русский добавлен по образцу испанского (коммит апстрима `a20a0a6`). Новый язык прописывается в 5 местах: `i18n/init.ts`, `i18n/useLanguageLabels.ts`, `utils/languages.ts`, `i18next-parser.config.json` и `LANGUAGES` в `meet/settings.py`. Ещё нужно добавить строку с названием языка во все `django.po`.

Юридические тексты (`legals.json`, `termsOfService.json`) пока дословно переведены с французского и описывают французского оператора. Для нашей практики их нужно заменить своими, с учётом 152-ФЗ и врачебной тайны.
